# Ефект Черенкова

Інтерактивна навчальна модель до практичного заняття з фізики магістерського рівня.

**Автор:** Роман Ткаченко, ОФ-61мп, ФМФ, КПІ ім. Ігоря Сікорського.

**Відкрити модель:** https://RomanTkachenko-dev.github.io/cherenkov-model/

## Можливості

- Зміна швидкості частинки, параметрів дисперсії, довжини хвилі, довжини треку, ефективності реєстрації та масштабу оптики.
- Спектральна густина очікуваної кількості зареєстрованих фотонів і геометричні кільця Черенкова.
- Порогова область емісії, середній сигнал, середній радіус і його хроматична ширина.
- Відновлення параметрів задачі 3 однією кнопкою.

Модель використовує формулу Франка—Тамма, закон дисперсії n(λ) = A + B/λ² та чисельне інтегрування на 2400 інтервалах у смузі 300–600 нм. У законі дисперсії λ задано в мкм. A та B — навчальні параметри, не паспортні дані конкретного матеріалу. Відображення r = f tan θ ідеалізоване, без заломлення на межі й аберацій. Яскравість кілець умовна.

Джерело: [PDG, Passage of Particles Through Matter, §34.7.1 (2024)](https://pdg.lbl.gov/2024/reviews/rpp2024-rev-passage-particles-matter.pdf).

## Локальний запуск

Завантажте файли репозиторію та відкрийте `index.html` у браузері. Залежності та збирання не потрібні. Модель працює автономно.
